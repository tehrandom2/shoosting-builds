Liner notes

Every track was generated on the developer's own machine with ACE-Step 1.5, an Apache 2.0 music model, from a plain text prompt. No samples, no reference recordings, and no third-party audio went in. Open any track above to read the exact prompt and seed that made it. Same prompt, same seed, same song.

In the game, the MusicPlayer shuffles this pool and crossfades between tracks. It never plays the same one twice in a row. The shuffle button here follows the same rule.
